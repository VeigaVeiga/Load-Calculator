# Load Calculator V1

A learning-oriented React + TypeScript + Vite + Three.js container loading demo.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## What to learn first

1. `src/types.ts` — TypeScript data structures.
2. `src/data.ts` — sample cargo and container data.
3. `src/App.tsx` — React state, components, and calculations.
4. `src/components/ContainerScene.tsx` — React Three Fiber / Three.js.
5. The simple shelf algorithm in `ContainerScene.tsx` will later be replaced by a real packing algorithm.
